# 快速开始指南

## 方式一：使用 Node.js 脚本（推荐）

1. 运行生成脚本：
```bash
node generate-project.js
```

2. 安装依赖：
```bash
npm install
```

3. 查看生成的文件并继续完成剩余代码

## 方式二：手动创建

1. 运行批处理文件创建目录：
```bash
create-dirs.bat
```

2. 按照 `源代码文件清单.md` 手动创建每个文件
