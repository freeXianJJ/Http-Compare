## 💡 使用提示

### 基础测试流程
1. **配置服务**
   - 旧服务：填写Host、Port、Token（可选）
   - 新服务：填写Host、Port、Token（可选）

2. **配置接口**
   - 接口名称：给接口起个名字
   - 请求方法：选择GET/POST等
   - 接口路径：输入路径，如 /api/user/123

3. **发送测试**
   - 点击"发送请求并对比"按钮
   - 等待请求完成

4. **查看结果**
   - 绿色✓ = 完全一致
   - 红色✗ = 存在差异
   - 查看详细差异列表

### 示例配置

**测试本地服务**
```
旧服务：
  Host: localhost
  Port: 8080
  Token: old-service-token-xxx

新服务：
  Host: localhost  
  Port: 8081
  Token: new-service-token-yyy

接口：
  名称: 获取用户信息
  方法: GET
  路径: /api/user/123
```
