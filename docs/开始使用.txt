              HTTP 接口对比测试工具 - 快速开始指南
====================================================================

✨ 一键生成完整项目（推荐）
====================================================================

1. 打开命令行（CMD），切换到项目目录：
   
   cd /d d:\Project\http


2. 运行MVP项目生成脚本：
   
   node create-mvp.js


3. 安装依赖：
   
   npm install


4. 启动开发服务器：
   
   npm run dev


5. 浏览器访问：
   
   http://localhost:3000


====================================================================
项目说明
====================================================================

这是一个最小可运行版本（MVP），包含以下功能：

✅ 服务配置（新旧服务独立的Host、Port、Token）
✅ 接口配置（URL、HTTP方法）
✅ 双端并发请求
✅ 响应对比（状态码、响应体）
✅ 差异可视化展示
✅ 数据本地持久化

====================================================================
使用示例
====================================================================

1. 配置服务：
   - 旧服务：localhost:8080
   - 新服务：localhost:8081
   - Token：可选填

2. 配置接口：
   - 方法：GET
   - 路径：/api/user/123

3. 点击"发送请求并对比"

4. 查看结果：
   - 绿色提示：响应完全一致 ✓
   - 红色提示：存在差异 ✗
   - 查看详细差异列表

====================================================================
常见问题
====================================================================

Q: npm install 很慢？
A: 使用国内镜像：npm config set registry https://registry.npmmirror.com

Q: 端口被占用？
A: 修改 vite.config.ts 中的 port 为其他值

Q: 找不到模块？
A: 确保已运行 npm install

Q: CORS跨域问题？
A: 配置后端允许跨域，或使用浏览器插件
